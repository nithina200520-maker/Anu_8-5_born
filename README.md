# Birthday Wish – Anu 🎂

## Run in VS Code
1. Unzip this folder and open it in VS Code (File > Open Folder).
2. Install the **Live Server** extension (Ritwick Dey).
3. Right-click `index.html` > **Open with Live Server**.
   (Double-clicking `index.html` in a browser also works.)

## Structure
```
index.html        page structure
css/style.css     all styling and animations
js/script.js      all logic (wishes, confetti, fireworks, slideshow)
images/           home photo, surprise photo, 10 memory slideshow photos
```

## Edit tips
- Change the default name: `value="Anu"` in `index.html`.
- Change wish messages: `WISHES` array at the top of `js/script.js`.
- Swap slideshow photos: replace files in `images/` or edit the `MEMORY_IMGS` list in `js/script.js`.
- Fonts (Pacifico, Nunito) load from Google Fonts, so internet is needed for them.
